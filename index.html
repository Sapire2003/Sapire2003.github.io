02Engineering · Simulation

Wildfire Detection System Trade Study

Compares 375 ways to build a wildfire early-warning system from camera towers, drones, and satellites. It simulates 3,000 fires for each design to find which ones meet the goals within budget.

375 designs
each tested on the same 3,000 simulated fires
35% vs. 46%
how often the cheapest vs. sturdiest passing design held up
  • Found that no single sensor type works alone: every passing design mixes them.
  • Showed that the cheapest design passes on paper with almost no margin and fails most of the time when the assumptions shift.
  • Recommended surveying tower sight lines and testing radio links before spending money, since those drive most of the risk.

All inputs are documented, illustrative assumptions. Changing one regenerates every result.

04Statistics · Fairness

Mortgage Fairness Audit

Checks whether 88,000 real New York mortgage applications were approved at different rates by race, ethnicity, sex, or age.

9.7 → 5.7 pts
Black–White approval gap, before and after accounting for finances and lender
0.85 → 0.92
fairness score after removing one neighborhood input (1.0 = equal)
  • Showed that a model that never sees race can still treat groups unequally through neighborhood data.
  • Caught data that would have let a model "cheat" by seeing the outcome in advance.
  • Showed that the standard fairness check can pass even when one group is denied 2.4 times as often.

Public mortgage data has no credit scores, so the gaps flag a need for review. They aren't proof of discrimination.

05Finance · Machine learning

Loan Default Predictor

Predicts which personal loans will go unpaid, using 164,000 real loans, and runs as a web service that scores an application instantly.

Beat the lender
ranked risk better than the lender's own interest rates
Plain reasons
every decline comes with its main reasons
  • Kept the model's logic common-sense, so a higher income can never make an applicant look riskier.
  • Warns automatically when new applicants start to look different from the ones it learned from.
  • Saves every decision and its reasons in a PostgreSQL database, and refuses to decide if it can't save one, so every decision can be audited.
  • Built to run on AWS and backed by 33 automated tests.
