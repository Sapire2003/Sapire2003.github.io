# Portfolio site

A single-page portfolio, with no build step. Open `index.html` in a browser to view it.

## Before publishing

1. Publish the three project repositories on GitHub.
2. In `index.html`, find `const REPOS` near the bottom and paste in your GitHub links. Buttons without a link stay hidden, so the page never shows a broken link.
3. If you rerun the BNPL monitor, copy its new `reports/dashboard.html` to `demo/bnpl-dashboard.html`.

## Publish free with GitHub Pages

1. Create a repository named `<your-username>.github.io`.
2. Upload everything in this folder to it: `index.html`, `assets/`, and `demo/`.
3. In the repository, open **Settings → Pages**, then choose **Deploy from a branch** and the `main` branch.
4. The site goes live at `https://<your-username>.github.io` within a few minutes. Put that link on your resume and LinkedIn.

The page shows your email and LinkedIn, but not your phone number, since it will be public.
